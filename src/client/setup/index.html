Connect Gmail accounts

Bind Personal and Work separately. Each account is stored in its own database silo. Sync imports the latest conversations up to your chosen limit as a background job and shows progress here.

Google Cloud Pub/Sub

Authorize a Google account in this browser for the local Pub/Sub listener. Create the topic and subscription and grant that account Pub/Sub Subscriber access in Google Cloud Console.

Google only accepts OAuth callbacks on localhost, so connect accounts from this machine. Keep the server bound to localhost and never commit your OAuth credentials.
